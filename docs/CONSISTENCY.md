# 문서 일관성 규칙

첨부한 보고서가 어떤 형식이든, 어떤 기업이든 PPT가 **같은 기준·같은 표기**로 만들어지도록 지키는 규칙입니다.
각 규칙은 `tests/consistency.test.js`의 같은 번호 테스트로 확인합니다. 규칙을 바꾸면 테스트도 함께 고치세요.

| # | 규칙 | 확인 방법 |
|---|---|---|
| 1 | 재무 연도는 **기본 3개년**, 설립 연도에 따라 2개년·1개년. 모든 재무 시계열 길이가 표시 연수와 같다. | 1·2·3개년, 설립 전 빈 열이 있는 보고서 4종 |
| 2 | 연도가 축인 모든 차트는 **같은 표시 연도**를 쓴다(법인세 부담률은 값이 있는 연도만). | 모든 차트의 가로축 비교 |
| 3 | 같은 수치는 모든 장에서 **같은 값**으로 쓴다(종합 진단·재무① 매출, 차트 값 = 분석 값). | 슬라이드 글자·차트 값 대조 |
| 4 | 작성자 정보는 표지·마지막 장(`소속  \|  컨설턴트`)과 바닥글(`소속 컨설턴트`)에 **같은 이름**으로 들어간다. | 표지·마지막 장·레이아웃 XML |
| 5 | **엑셀과 PDF**로 올린 같은 보고서는 같은 PPT 글자·차트가 나온다. | `sample_3y.xlsx` ↔ `sample_3y.pdf` |
| 6 | 증감은 `▲ 증가`(적색) / `▼ 감소`(청색)로만 쓰고, `undefined`·`NaN` 같은 계산 오류 글자가 없다. | 전 슬라이드 글자 검사 |
| 7 | 1개년 보고서는 전년 대비·"○년 대비 ○배"를 만들지 않는다. | 1개년 보고서 |
| 8 | 같은 입력이면 매번 같은 결과(날짜만 다름). | 두 번 생성 비교 |
| 9 | 15장 구성과 순서, 장 번호 표기(01 기업 개요 … 10 실행 로드맵)는 입력과 관계없이 같다. | 장 머리표 비교 |

## 표기 원칙

- **단위**: 금액은 백만원(원본 천원 ÷ 1,000), 비율은 %, 비율 차이는 %p, 회전율은 회, 배수는 배.
- **반올림**: 금액은 정수, 비율은 소수 첫째 자리, 매출 대비 보험료·노무비 비율은 소수 둘째 자리.
- **증감 계산**: `(당기 − 전기) ÷ |전기| × 100`. 전기가 0이면 금액 차이(`▲ 증가 115백만`), 300%를 넘는 변화도 금액 차이로 씁니다.
- **재무제표의 `-`** 는 0원, **재무비율의 `-`** 는 산출 불가(빈칸)로 봅니다.
- **보고서에 없는 정보**는 "없음"으로 단정하지 않고 "확인 필요"로 씁니다.
- **출처 줄**: 모든 내용 장 아래에 `출처: 한국평가데이터 기업종합보고서 (조회일)`과 근거 표를 적습니다.
