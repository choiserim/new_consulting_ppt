# 보고서 인식 방식

`src/core.js`는 보고서를 "행 = 칸 목록"으로 바꾼 뒤, 칸 이름과 구역 제목으로 내용을 찾습니다.
엑셀과 PDF가 같은 행 목록이 되도록 맞추는 것이 일관성의 핵심입니다.

## 1. 파일 → 행

| 형식 | 방법 |
|---|---|
| `.xls` `.xlsx` | 모든 시트를 순서대로 읽고 빈 칸을 버립니다. 칸 안 줄바꿈은 공백으로 바꿉니다. |
| `.pdf` | 글자 조각을 y좌표로 줄을 묶고, x 간격이 글자 높이의 1.2배 이상이면 칸을 나눕니다. 두 줄로 나뉜 항목명("총자산순이익률" / 숫자 / "(ROA)")은 한 행으로 합칩니다. `△1,234`·`(1,234)`는 음수로 읽습니다. |

`COPYRIGHT …`, `3/29` 같은 쪽 머리·꼬리는 버립니다.

## 2. 행 → 내용

| 내용 | 찾는 방법 |
|---|---|
| 기업개요 | `기업명`, `대표자명`, `종업원수`, `설립년월`, `기업규모`, `주소`, `표준산업분류(10차)` … 칸 바로 다음 칸 |
| 결산연도 | `결산일자 : YYYY-MM-DD` |
| 재무제표(천원) | `재무상태표`·`손익계산서`·`제조원가명세서`·`이익잉여금처분계산서` 제목 뒤, `계정명 \| YYYY-12-31 …` 머리행의 연도. 각 행은 오른쪽 끝 숫자들을 연도에 맞춥니다. |
| 요약 재무(백만원) | 상세 재무제표가 없을 때 `요약 재무상태표`·`요약 손익계산서` 사용 |
| 재무비율 | `재무비율` 구역에서 "항목명 + 숫자들" 묶음 |
| 업종 비교 | `재무진단` 구역의 `항목 \| 업종평균 \| ▲ 증가/▼ 감소 \| 조회기업` 행 |
| 동종업계 규모 | `조회기업`·`상위25%`·`평균`·`하위25%` 행 |
| 업계 순위 | `NNN위` 바로 다음 칸이 기업명인 칸 |
| 주주·임원 | `주요주주현황`(지분율은 100 이하 마지막 숫자), `경영진현황` |
| 거래처 | `구매처현황`·`판매처현황`의 `기업명 \| 사업자번호 \| 대표자명 \| 거래비중` |
| 인증·특허 | `벤처 \| 이노비즈 \| 메인비즈 \| 연구개발전담부서 \| 부설연구소` 다음 행, `특허 … 상표권` 다음 `N건` 4개 |
| 사업목적 | `사업목적` 구역의 `N. 내용` |
| 나라장터 | `입찰건수 \| 낙찰건수` 다음 행, `총 낙찰금액` 다음 행 |

## 3. 새 보고서 배치에 맞추기

1. 화면의 **추출 원문 보기**로 문제 행을 확인합니다.
2. `parseReport`의 해당 구역 처리에 조건을 더합니다.
3. `scripts/make-fixtures.js`에 그 배치를 흉내 낸 가상 행을 넣고 `npm run fixtures && npm test`로 확인합니다.
