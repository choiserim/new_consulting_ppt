# 기업진단 PPT 생성기

한국평가데이터(KoDATA) **기업종합보고서**(엑셀 `.xls`·`.xlsx` 또는 `.pdf`)를 올리면, 재무·세무·노무·보험·정관·인증·법무 **7대 영역**을 진단해 기업 담당자에게 전달할 **컨설팅 PPT(15장)** 를 브라우저에서 바로 만들어 줍니다.

- 서버가 없습니다. 파일은 **사용자의 브라우저 안에서만** 읽고 처리하며 어디에도 전송·저장하지 않습니다.
- 엑셀로 올리든 PDF로 올리든 **같은 보고서면 같은 PPT 내용**이 나오도록 테스트로 지킵니다. 규칙은 [docs/CONSISTENCY.md](docs/CONSISTENCY.md)에 있습니다.

## 바로 쓰기

| 방법 | 설명 |
|---|---|
| GitHub Pages | 저장소 **Settings → Pages → Source: GitHub Actions**로 설정하면 `main`에 올릴 때마다 자동 게시됩니다(`.github/workflows/pages.yml`). |
| 단일 HTML 파일 | `npm run build` → `dist/기업진단_PPT_생성기.html`을 더블클릭해 엽니다. CI(Actions) 실행 결과의 `standalone-html` 아티팩트로도 받을 수 있습니다. |
| 로컬 서버 | `npm run serve` → http://localhost:8080 |

> 엑셀·PDF·PPT 처리 라이브러리는 CDN(jsDelivr)에서 불러오므로 **인터넷 연결이 필요**합니다.

## 사용 순서

1. **보고서 올리기** — 기업종합보고서 원본 파일을 끌어다 놓거나 선택합니다.
2. **추출 결과 확인** — 7대 영역 상태, 핵심 수치(▲ 증가 · ▼ 감소), 읽어 낸 항목을 확인합니다. 결산일자와 읽힌 연도가 다르면(예: PDF 오른쪽 열 잘림) 경고가 뜹니다.
3. **작성자 정보 입력 → PPT 만들기**

### 작성자 정보

| 칸 | 예시 | 들어가는 곳 |
|---|---|---|
| 컨설턴트 | `최세림 GFC` | 표지·마지막 장(소속과 함께), 파일 작성자 |
| 소속 · 브랜드 | `삼성센터법인지점` | 표지·마지막 장 |
| 바닥글 | `삼성센터법인지점 최세림 GFC` | 모든 내용 장의 바닥글 |

- 바닥글은 **"소속 + 컨설턴트 이름"으로 자동 연동**됩니다. 직접 고치면 연동이 풀리고, "소속 + 컨설턴트로 다시 채우기"로 되돌릴 수 있습니다.
- 입력값은 그 브라우저에만 기억됩니다(localStorage).

## 재무 연도 표시 규칙

- **기본 3개년**을 표시합니다.
- **설립 연도에 따라** 줄어듭니다: `표시 연수 = min(3, 결산연도 − 설립연도 + 1, 보고서에 있는 연수)`
  - 예) 설립 2019년, 결산 2025년 → 3개년(2023~2025)
  - 예) 설립 2024년, 결산 2025년 → 2개년(2024~2025)
  - 예) 설립 2025년, 결산 2025년 → 1개년(2025)
- 보고서에 열은 있지만 매출·자산이 모두 비어 있는 앞쪽 연도(설립 전)는 뺍니다.
- 1개년이면 전년 대비·증가율·"○년 대비 ○배" 문구를 만들지 않습니다.
- 표시 연도는 모든 차트·표·문구에 똑같이 적용되고, 출처 줄에 `재무 3개년(2023~2025) · 설립 2019년 기준`처럼 적힙니다.

## 슬라이드 구성 (15장)

표지 → 기업 개요 → 종합 진단(7대 영역 상태) → 재무 ①손익 ②재무상태·주요 계정 ③업종 비교 → 세무 ①핵심 리스크 ②공제·감면 → 노무 → 보험 → 정관 → 인증 → 법무 → 실행 로드맵 → 요청 자료

- **세무 ①** 은 금액 중요도에 따라 *가지급금 / 전기오류수정 / 이익잉여금* 중 하나를 자동으로 고릅니다.
- **보험** 권장 보장은 업종(제조 C → 생산물배상, 폐기물·환경 E → 환경책임, 공사수입 → 공사배상)과 차량 보유에 따라 달라집니다.
- **노무** 점검 항목은 종업원 5인·10인 기준으로 달라집니다.
- **법무** 는 거래처 대표자명이 당사 임원·주주 이름과 같으면 "특수관계 의심"으로 표시합니다(동일인 여부는 등기부로 확인 필요).
- 보고서에 없는 항목(인증·거래처·사업목적 등)은 "없음"으로 단정하지 않고 **"확인 필요"** 로 표시합니다.

## 개발

```bash
npm install          # 테스트용 라이브러리 설치 (Node 18 이상)
npm test             # 일관성·연도 규칙·엑셀/PDF 동일성 테스트
npm run build        # dist/ 에 단일 HTML과 아티팩트용 본문 생성
npm run fixtures     # 테스트용 가상 보고서(xlsx) 다시 만들기
```

### 폴더 구조

```
index.html                 화면(GitHub Pages 진입점)
src/core.js                보고서 읽기 · 분석 · PPT 생성 엔진 (브라우저/Node 공용)
src/app.js                 화면 동작(파일 올리기, 작성자 정보, 내려받기)
src/styles.css             화면 스타일(라이트/다크)
scripts/build-standalone.js  단일 HTML 빌드
scripts/make-fixtures.js     가상 기업 보고서 생성
tests/consistency.test.js    문서 일관성 테스트
tests/fixtures/            가상 기업(샘플정밀) 보고서 1·2·3개년, PDF
docs/CONSISTENCY.md        문서 일관성 규칙
docs/REPORT-FORMAT.md      보고서 인식 방식
```

### core.js 주요 함수

| 함수 | 하는 일 |
|---|---|
| `rowsFromWorkbook(XLSX, buf)` / `rowsFromPdf(pdfjsLib, buf)` | 파일을 "행 = 칸 목록" 형태로 바꿉니다. PDF는 줄·칸 간격으로 칸을 나누고, 두 줄로 나뉜 항목명을 합칩니다. |
| `parseReport(rows)` | 기업개요, 재무제표, 재무비율, 업종 비교, 주주·임원, 거래처, 인증, 사업목적 등을 읽습니다. |
| `analyze(d, now)` | 표시 연도 결정, 백만원 환산, 7대 영역 상태 판정. |
| `buildDeck(PptxGenJS, d, A, author)` | 15장 PPT를 만듭니다. |
| `normalizeAuthor({consultant, brand, footer})` | 작성자 정보 정리(바닥글 비면 "소속 + 컨설턴트"). |

## 개인정보 주의

- 실제 고객 보고서(`.xls`, `.pdf`)와 결과 PPT는 **저장소에 올리지 마세요.** `.gitignore`가 막아 두었습니다(`tests/fixtures/` 제외).
- 테스트 자료는 `scripts/make-fixtures.js`가 만드는 **가상 기업** 데이터입니다.

## 한계

- 한국평가데이터 보고서 배치를 기준으로 만들었습니다. 배치가 바뀌거나 스캔(이미지) PDF면 일부 항목을 읽지 못할 수 있습니다. 화면의 "추출 원문 보기"로 확인하고, 가능하면 엑셀 파일을 쓰세요.
- 인정이자(4.6% 단순 추정), 감면 적용 여부, 특수관계 의심 등은 판단을 대신하지 않는 **점검 신호**입니다. 세무·법률 판단은 원본 자료와 전문가 확인 후 확정하세요.
- 브라우저용 SheetJS(`xlsx@0.18.5`)는 npm 마지막 공개판입니다. 신뢰할 수 있는 보고서 파일만 올리세요.
